# Finance Real-Time Big Data Analysis Platform

基于大数据技术构建的金融实时行情分析平台。

## 项目简介

本项目实现黄金、白银、原油、铜等金融数据的实时采集、传输、存储、计算和可视化分析。

## 技术架构

- Kafka
  - 实时数据采集与消息传输

- PySpark
  - 实时流式计算

- Hadoop HDFS
  - 分布式数据存储

- Hive
  - 离线数据仓库分析

- Elasticsearch
  - 实时数据检索

- FastAPI
  - 后端服务接口

- Vue / HTML Dashboard
  - 数据可视化展示
